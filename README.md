# EduPlatform LMS

Plataforma LMS para la ensenanza de la redaccion en lengua castellana.

## Caracteristicas

- 101 usuarios
- 50 cursos
- 327 lecciones
- 497 recursos
- 1066 ejercicios
- 128 evaluaciones
- 8 logros
- Gamificacion
- Ranking
- Certificados
- Home publico

## Instalacion

Clonar el repositorio:

git clone https://github.com/Hernank10/eduplatform-lms-2026.git
cd eduplatform-lms-2026
pip install django
python manage.py migrate
python manage.py runserver 127.0.0.1:8015
